## About
This Chrome extension helps you save and manage your important tabs and URLs in one place. 

## Features
- Save any URL manually
- Save current tab with one click
- View saved links anytime
- Delete links easily
- Simple and clean UI

## Built with
 - HTML
 - CSS
 - JavaScript

## Use Case
Perfect for students, developers, or anyone who wants to keep track of useful links without cluttering bookmarks.
